# corpus_v2 — 멀티테넌트 합성 테스트 코퍼스

> **전체가 합성(창작) 문서다.** 테넌트명은 실제 고객사에서 따왔지만 정책 내용·수치·연락처는
> 전부 테스트용 창작이며 실제 정책과 무관하다. 외부 공유 금지.
> 생성: 2026-07-11. 굿피플은 국제구호개발 NGO로 확인되어 후원자 상담 도메인으로 재생성함.

## 구조

테넌트당 문서 10개 + 개정판(`.rev2`) 1개 = 66파일. 공통 주제(환불·배송·교환) + 도메인 특화 주제로 구성.
모든 문서: 문서번호 체계, 문서 간 §상호참조, 조건 분기 3곳 이상, 테넌트당 표 문서 ≥1 + 장문(3,500자+) ≥1.

**포맷 구성 (테넌트당, 파서 경로 전체 커버)**: PDF 3(01·03·05, +01의 rev2도 PDF) / DOCX 3(02·04·07) / MD 1(06) / TXT 1(08, 상담 스크립트 — 헤딩 없는 평문 청킹 테스트) / XLSX 2(09·10, 각 3시트·1시트 1표·첫 행 헤더·A1 시작·수치는 숫자 타입).
PDF·DOCX의 md 원본은 `_src/<tenant>/`에 보관 (수정 후 재변환용 — `_src`는 업로드 대상 아님).

| 테넌트 | 디렉터리 | 도메인 | 문서번호 |
|---|---|---|---|
| 써머스코리아 | `summers/` | 보온병·텀블러 제조사 몰 | SUM-CS-001~006 |
| 홈플러스 | `homeplus/` | 대형마트 온라인몰 | HP-CS-001~006 |
| 아더에러 | `adererror/` | 디자이너 의류 브랜드 | ADR-CS-001~006 |
| 아로마니카 | `aromanica/` | 화장품(스킨케어) | ARM-CS-001~006 |
| 굿피플 | `goodpeople/` | 국제구호개발 NGO — 후원자 상담(기부·결연·영수증) | GP-CS-001~006 |
| 하림 | `harim/` | 식자재·닭고기 직영몰(신선·냉동) | HR-CS-001~006 |

## 테넌트 격리 카나리아 — 핵심 수치 대조표

공통 주제의 **핵심 수치를 테넌트마다 다르게** 박아뒀다. 격리(WHERE 절)가 깨지면
다른 테넌트 수치가 답변에 섞여 나오므로, 답변의 숫자만 보고 누출을 판별할 수 있다.
gold 질의 정답 검증 기준으로도 사용.

| 항목 | 써머스 | 홈플러스 | 아더에러 | 아로마니카 | 굿피플 | 하림 |
|---|---|---|---|---|---|---|
| 단순변심 반품 기간 | 14일 | 30일 | 7일 | 미개봉 14일 | 해당 없음(비상품) | **불가**(신선) |
| 무료배송 기준 | 3만원 | 4만원 | 5만원 | 3만원 | 해당 없음 | 5만원 |
| 기본 배송비 | 3,000원 | 3,000원 | 3,000원 | 2,500원 | 해당 없음 | 3,000원 |

## `.rev2.pdf` — 버저닝 테스트용 개정판

각 테넌트의 환불 정책 문서(01번) 개정판. **원본과 같은 파일명으로 바꿔 재업로드**하면
엎어치기 버저닝(v1→v2)이 되고, 개정 수치로 "옛 답변 캐시 무효화 + 새 수치 답변"을 검증한다.

| 테넌트 | rev2 개정 수치 |
|---|---|
| 써머스 | 왕복 배송비 6,000→7,000원, 하자 반품 30→60일, 환불 3→5영업일 |
| 홈플러스 | 무료배송 4만→5만원, 반품 배송비 3,000→3,500원, 전결 한도 5만→10만원 |
| 아더에러 | 교환 왕복 5,000→6,000원, 환불 3→5영업일, 회수비 2,500→3,000원 |
| 아로마니카 | 미개봉 반품 14→7일, 반품 배송비 5,000→6,000원, 환불 승인 3→2영업일 |
| 굿피플 | 이의신청 30→60일, 환불 처리 5→3영업일, 심의 회신 10→7영업일 |
| 하림 | 무료배송 5만→6만원, 가공품 반품 배송비 6,000→7,000원, 기본 배송비 3,000→3,500원 |

## 사용법

1. 테넌트별로 **해당 tenant_id로만** 업로드한다 (디렉터리 간 교차 업로드 금지 — 격리 전제).
2. gold 질의 제작 시 이 코퍼스 버전과 gold셋 버전을 짝(corpus v2 ↔ gold v2)으로 관리하고,
   corpus v1(kms_01~10) 결과와는 비교하지 않는다.
