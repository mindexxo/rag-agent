# 아더에러 온라인몰 환불·반품 정책

문서번호: ADR-CS-001 (Rev.1)
시행일: 2026-03-02
관리부서: CS운영팀

## 1. 목적 및 적용 범위

본 문서는 아더에러 공식 온라인몰에서 판매된 상품의 환불·반품·교환 업무 처리 기준을 정한다. 오프라인 매장 및 입점 편집숍 구매 건에는 적용하지 않으며, 해당 건은 구매처 정책을 따르도록 안내한다.

## 2. 반품(환불) 규정

### 2.1 신청 기한

온라인몰 구매 상품의 반품은 상품 수령일로부터 7일 이내 신청을 원칙으로 한다. 수령일은 택배사 배송완료 처리일 기준으로 산정한다. 단, 상품 불량 또는 오배송의 경우 수령일로부터 30일 이내까지 접수를 허용한다.

### 2.2 반품 가능 조건

다음 조건을 모두 충족한 경우에만 반품을 승인한다.

- 상품 택(tag), 라벨, 부속품이 훼손 없이 부착·동봉되어 있을 것
- 착용 흔적, 세탁 흔적, 향수·화장품 등 오염이 없을 것
- 상품 박스 및 더스트백 등 기본 패키지가 동봉되어 있을 것

### 2.3 반품 불가 사유

다음 각 호에 해당하는 경우 반품을 승인하지 않는다.

- 수령일로부터 7일 경과 후 신청 건 (불량·오배송 제외)
- 택 제거, 수선, 세탁 등으로 상품 가치가 훼손된 경우
- 세일(할인) 상품: 환불 불가이며 동일 상품 교환만 가능하다 (ADR-CS-004 §2 참조)
- 고객 주문 제작 상품(이니셜 각인 등)

### 2.4 환불 처리 절차

반품 상품이 물류센터에 입고되면 검수 후 3영업일 이내에 환불을 실행한다. 카드 결제 건은 승인 취소로, 계좌이체·가상계좌 건은 고객 지정 계좌 입금으로 처리한다. 검수 결과 반품 불가 사유가 확인되면 고객에게 유선 안내 후 상품을 반송하며, 반송 배송비는 고객이 부담한다.

### 2.5 결제 수단별 환급 안내

환불 실행 후 실제 환급 반영까지의 소요 기간은 결제 수단별로 다름을 안내한다. 신용카드는 카드사에 따라 승인 취소 반영에 3~7일이 소요될 수 있고, 간편결제는 각 결제사 정책을 따르며, 계좌 환불은 환불 실행 당일 입금된다. 카드사 반영 지연은 회사가 통제할 수 없는 구간임을 안내한다.

## 3. 교환 규정

### 3.1 단순 변심 교환

색상·사이즈 변경 등 단순 변심 교환 시 왕복 배송비 5,000원을 고객이 부담한다. 교환은 1회에 한하며, 재교환 요청 시에는 반품 후 재구매로 안내한다.

### 3.2 불량·오배송 교환

당사 귀책(불량, 오배송)으로 판정된 교환 건은 왕복 배송비를 회사가 전액 부담한다. 불량 여부 판정은 ADR-CS-006 불량 판정 기준을 따른다.

## 4. 배송비 부담 기준

### 4.1 단순 변심 반품

반품 회수 배송비 2,500원을 고객이 부담하며, 환불 금액에서 차감한다. 최초 주문이 5만원 이상 무료배송으로 출고된 건은 반품으로 인해 잔여 주문 금액이 5만원 미만이 되는 경우 최초 배송비 3,000원을 추가 차감한다.

### 4.2 당사 귀책 반품

불량·오배송 건은 회수 배송비 전액을 회사가 부담하며 환불 금액에서 차감하지 않는다.

## 5. 적립금·쿠폰 처리

### 5.1 사용 쿠폰 복원

전체 주문 반품 시 사용한 쿠폰은 유효기간이 남아 있는 경우 자동 복원한다. 부분 반품으로 잔여 주문 금액이 쿠폰 사용 조건 미만이 되는 경우, 쿠폰 할인액을 환불 금액에서 차감하고 쿠폰은 복원하지 않는다.

### 5.2 적립금 회수

구매 확정으로 지급된 적립금은 반품 승인 시 자동 회수한다. 이미 사용한 적립금이 회수 대상인 경우 부족분을 환불 금액에서 차감한다.

## 6. 예외 및 에스컬레이션

기한 초과 건 중 고객 귀책이 아닌 사유(택배사 보관 지연 등)가 소명되는 경우 CS 팀장 승인으로 예외 승인할 수 있다. 예외 승인 건은 상담 이력에 승인자와 사유를 기록한다.
