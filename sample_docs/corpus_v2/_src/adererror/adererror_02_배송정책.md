# 아더에러 온라인몰 배송 정책

문서번호: ADR-CS-002 (Rev.1)
시행일: 2026-03-02
관리부서: CS운영팀

## 1. 배송비 기준

### 1.1 기본 배송비

주문 금액 5만원 미만 건은 배송비 3,000원을 부과한다. 주문 금액 5만원 이상 건은 무료배송을 적용한다. 주문 금액은 할인·쿠폰 적용 후 실결제 금액 기준으로 산정한다.

### 1.2 도서·산간 지역

제주 및 도서·산간 지역은 기본 배송비와 별도로 추가 배송비 3,000원을 부과한다. 무료배송 대상 주문이라도 추가 배송비는 부과한다.

## 2. 출고 및 배송 기간

### 2.1 일반 상품

결제 완료일 기준 2영업일 이내 출고를 원칙으로 한다. 출고 후 배송 소요 기간은 통상 1~3일이며, 택배사 사정에 따른 지연은 보상 대상이 아니다.

### 2.2 예약 판매 상품

예약(프리오더) 상품은 상품 상세 페이지에 고지된 출고 예정일을 따른다. 출고 예정일로부터 7일 이상 지연되는 경우 고객에게 지연 안내 및 주문 취소 선택권을 제공한다.

## 3. 배송 관련 문의 처리

### 3.1 미수령 신고

배송완료 처리 후 미수령 신고가 접수되면 택배사 배송 사진과 위치를 우선 확인한다. 분실이 확인되면 택배사 배상 절차와 별개로 동일 상품 재출고 또는 환불 중 고객이 선택하도록 안내한다. 단, 고객이 지정한 무인함·문앞 보관 요청 이후의 분실은 회사 배상 대상에서 제외한다.

### 3.2 주소 변경

출고 전 건은 주문 관리 시스템에서 즉시 변경 처리한다. 출고 후 건은 택배사 반송 후 재발송으로 처리하며, 재발송 배송비 3,000원은 고객이 부담한다. 단, 주문 시 입력된 주소가 정확했으나 택배사 오분류로 반송된 경우 재발송 배송비를 부과하지 않는다.

### 3.3 합배송·분할 배송

동일 고객의 미출고 주문 2건 이상은 요청 시 합배송 처리할 수 있다. 품절 임박 상품과 예약 상품이 한 주문에 포함된 경우 일반 상품을 먼저 출고하는 분할 배송을 기본으로 하며, 분할 배송으로 인한 추가 배송비는 부과하지 않는다.

## 4. 반품·교환 배송비

반품·교환 시 배송비 부담 기준은 ADR-CS-001 §4를 따른다.
