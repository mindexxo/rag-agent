# 아더에러 사이즈 교환 가이드

문서번호: ADR-CS-003 (Rev.1)
시행일: 2026-03-02
관리부서: CS운영팀

## 1. 안내 원칙

아더에러 상품은 유니섹스 오버핏 실루엣을 기본으로 하므로, 사이즈 문의 시 평소 착용 사이즈보다 한 치수 작은 사이즈를 우선 검토하도록 안내한다. 상담원은 고객의 평소 착용 브랜드 사이즈를 확인한 뒤 아래 실측 스펙 기준으로 안내하며, "딱 맞는다"는 단정적 표현 대신 실측 수치를 제시하는 것을 원칙으로 한다.

## 3. 사이즈 교환 절차

### 3.1 신청 기한 및 조건

사이즈 교환은 상품 수령일로부터 7일 이내 신청 건에 한하여 접수한다. 택 부착, 미착용 등 반품 가능 조건(ADR-CS-001 §2.2)을 동일하게 적용한다.

### 3.2 배송비 부담

사이즈 교환은 단순 변심 교환으로 분류하며 왕복 배송비 5,000원을 고객이 부담한다. 단, 상품 상세 페이지 표기 실측치와 실제 상품 실측치의 차이가 3cm를 초과하는 경우 표기 오류로 간주하여 왕복 배송비를 회사가 부담한다.

### 3.3 재고 없는 사이즈로의 교환 요청

교환 희망 사이즈가 품절인 경우 다음 순서로 안내한다.

1. 재입고 예정이 확인되는 경우: 재입고 대기 교환 접수 (최대 14일 보류)
2. 재입고 예정이 없는 경우: 반품 후 환불로 전환 안내. 이 경우 세일 상품이라 하더라도 교환 불가에 따른 예외로 환불을 승인한다 (ADR-CS-004 §2.3 참조).

### 3.4 교환 횟수 제한

사이즈 교환은 주문 건당 1회를 원칙으로 한다. 1회 교환 후 재교환을 요청하는 경우 반품 후 재구매로 안내하며, 이때 반품 배송비 기준은 ADR-CS-001 §4.1을 따른다.

## 4. 상담 시 유의사항

- 신발류는 브랜드 자체 몰드 특성상 정사이즈보다 5mm 크게 나오는 편이므로 반 사이즈 다운을 안내한다.
- 니트류는 착용·세탁 후 늘어남이 발생할 수 있어 교환 검수 기준이 엄격함을 사전 고지한다.
- 고객이 실측 방법을 문의하면 "단면 기준(펼친 상태에서 좌우 끝 직선 거리)"임을 안내한다.

## 5. 사이즈 상담 표준 절차

1. 고객의 평소 착용 사이즈와 선호 핏(정핏/오버핏)을 확인한다.
2. 해당 품목의 §2 실측 스펙을 안내하고, 고객이 보유한 유사 품목 실측과 비교를 권장한다.
3. 두 사이즈 사이에서 고민하는 경우, 오버핏 선호 고객에게는 큰 사이즈를, 정핏 선호 고객에게는 작은 사이즈를 안내한다.
4. 상담원의 안내는 참고 정보이며 최종 선택은 고객 판단임을 고지하고, 사이즈 불만족 시 §3.2의 교환 배송비 기준이 적용됨을 함께 안내한다.
