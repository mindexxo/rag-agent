# 아더에러 세일·한정판 상품 정책

문서번호: ADR-CS-004 (Rev.1)
시행일: 2026-03-02
관리부서: CS운영팀

## 1. 적용 대상

본 문서는 온라인몰에서 할인가로 판매되는 세일 상품과 한정 수량으로 발매되는 한정판(콜라보레이션 포함) 상품의 상담 처리 기준을 정한다. 세일 상품 여부는 결제 시점 기준으로 판정하며, 쿠폰 할인만 적용된 정상가 상품은 세일 상품으로 분류하지 않는다.

## 2. 세일 상품 규정

### 2.1 환불 불가 원칙

세일 상품은 단순 변심에 의한 환불이 불가하며, 동일 상품의 색상·사이즈 교환만 가능하다. 이 원칙은 상품 상세 페이지와 결제 단계에서 고지되며, 상담 시 고지 사실을 근거로 안내한다. 교환 시 왕복 배송비 5,000원은 고객이 부담한다.

### 2.2 예외: 당사 귀책

세일 상품이라도 불량 또는 오배송으로 판정된 경우에는 환불이 가능하며, 왕복 배송비는 회사가 부담한다. 불량 판정은 ADR-CS-006을 따른다.

### 2.3 예외: 교환 불가 상황

교환 희망 옵션이 전 사이즈·전 색상 품절이고 재입고 예정이 없는 경우, 교환 수단이 소멸한 것으로 보아 환불을 승인한다. 이 경우 반품 회수 배송비는 고객이 부담한다 (ADR-CS-001 §4.1 준용).

### 2.4 세일 전환 보상 요청

정상가 구매 후 해당 상품이 세일에 들어간 경우, 결제일로부터 7일 이내 건에 한하여 차액을 적립금으로 보상한다. 7일 경과 건은 보상하지 않는다.

## 3. 한정판(콜라보) 상품 규정

### 3.1 구매 제한

한정판 상품은 1인 1주문, 주문당 품목별 1점으로 구매를 제한한다. 동일 수령인·동일 주소로 중복 주문이 확인되면 사전 안내 없이 후순위 주문을 취소할 수 있다.

### 3.2 교환·환불 제한

한정판 상품은 재고 특성상 사이즈 교환이 불가하며, 반품(환불)은 수령일로부터 7일 이내 미개봉·택 부착 상태에 한하여 승인한다. 개봉 후에는 불량 판정 건만 처리하며, 불량 건은 동일 상품 재고가 없는 경우 환불로 처리한다.

### 3.3 래플(응모) 발매 건

래플 방식으로 발매된 상품은 당첨 후 24시간 이내 결제를 완료하지 않으면 당첨이 자동 취소되며 차순위 대기자에게 구매 권한이 이관된다. 당첨 취소 건에 대한 복원 요청은 수용하지 않는다. 래플 상품의 반품·교환 기준은 §3.2를 동일하게 적용한다.

### 3.4 리셀 관련 주의

리셀(재판매) 목적 대량 구매가 의심되는 주문은 주문 검토 대상이며, 취소될 수 있음을 안내한다. 리셀 플랫폼 등 개인 간 거래로 취득한 상품은 구매 이력 확인이 불가하므로 교환·환불·불량 접수 대상에서 제외한다. 정품 여부 감정 요청에는 응하지 않으며, 공식 온라인몰과 공식 매장 구매 건만 정품 보증 대상임을 안내한다.

## 4. 상담 처리 유의사항

- 세일 상품 환불 요구가 강성 민원으로 발전하는 경우 규정 §2.1 고지 근거(상세 페이지·결제 단계 동의)를 안내하고, 지속 시 CS 팀장에게 이관한다.
- 한정판 발매 직후에는 문의가 집중되므로, 결제 오류로 인한 중복 결제 건은 당일 우선 처리한다.
- 세일 상품과 정상가 상품이 한 주문에 섞여 있는 경우, 환불 가능 여부는 상품 단위로 판정한다. 정상가 상품만 반품하는 부분 반품 시 배송비 차감 기준은 ADR-CS-001 §4.1을 적용한다.
- 세일 기간 종료 후 접수된 교환 건도 결제 시점에 세일가였다면 세일 상품 규정을 적용한다. 교환 출고 시 추가 차액을 청구하지 않는다.
- 한정판 상품의 불량 접수 시 재고 소진으로 교환이 불가한 경우가 많으므로, 접수 단계에서 환불 처리 가능성을 사전 고지한다.
