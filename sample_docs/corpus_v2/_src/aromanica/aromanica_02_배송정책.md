# 아로마니카 배송 정책 (ARM-CS-002)

문서번호: ARM-CS-002 | 시행일: 2026-01-02 | 적용 대상: 아로마니카 온라인몰 국내 배송

## 1. 배송비 기준

- 기본 배송비는 2,500원으로 한다.
- 1회 주문 금액 30,000원 이상(할인·쿠폰 적용 후 실결제 금액 기준)인 경우 배송비를 무료로 한다.
- 도서·산간 지역은 추가 배송비 3,000원을 부과한다. 추가 배송비는 주문 금액과 무관하게 면제되지 않는다.

## 2. 배송 소요 기간

- 평일 오후 2시 이전 결제 완료 건은 당일 출고를 원칙으로 한다.
- 오후 2시 이후 결제 건, 주말·공휴일 결제 건은 익영업일에 출고한다.
- 출고 후 수령까지 통상 1~3영업일이 소요됨을 안내하며, 특정 도착일을 보장하는 안내는 하지 않는다.

## 3. 배송 관련 조건 분기

1. 출고 전 배송지 변경 요청 → 출고 전 상태에 한하여 접수 가능하다. 출고 후에는 택배사 반송 절차로 처리한다.
2. 출고 후 7영업일 경과에도 미수령 → 택배사 배송 조회 후 분실 접수를 진행한다. 분실 확인 시 동일 상품 재발송 또는 전액 환불 중 고객이 선택하도록 안내한다.
3. 수령 시 외부 파손 확인 → 수령일로부터 3일 이내 파손 부위 사진을 접수받아 무상 교환 처리한다. 파손 건의 왕복 배송비는 회사가 부담한다.

## 4. 여름철 배송 유의사항

- 6월~8월에는 고온으로 인한 제형 변화(밤 타입, 립 제품 등) 가능성을 사전 고지한다.
- 고온 변형 우려 상품은 아이스팩 동봉 출고를 원칙으로 하며, 이로 인한 추가 비용은 부과하지 않는다.
- 수령 직후 냉장 보관 권장 안내는 ARM-CS-004 §3의 보관 기준을 따른다.

## 5. 묶음 배송·합배송

- 동일 고객이 같은 날 결제한 복수 주문은 출고 전 요청 시 합배송 처리하며, 합산 금액이 30,000원 이상이면 이미 결제된 배송비를 환불한다.
- 출고 처리가 시작된 주문은 합배송이 불가함을 안내한다.

## 6. 상담 시 유의사항

- 배송 지연 문의 시 출고일과 택배사 인수일을 구분하여 확인 후 안내한다.
- 배송비 환불 문의 시: 부분 반품으로 잔여 주문 금액이 30,000원 미만이 되는 경우, 기본 배송비 2,500원을 환불 금액에서 차감함을 안내한다.
