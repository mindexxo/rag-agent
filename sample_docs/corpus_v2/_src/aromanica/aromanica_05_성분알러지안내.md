# 아로마니카 성분·알러지 상담 안내 (ARM-CS-005)

문서번호: ARM-CS-005 | 시행일: 2026-01-02 | 적용 대상: 아로마니카 전 제품 성분 관련 문의

## 1. 상담 기본 원칙

- 성분 문의에는 제품 상세 페이지와 용기 표기의 전성분 목록을 기준으로 안내한다. 표기에 없는 성분 정보는 임의로 답하지 않고 품질관리팀 확인 후 회신한다.
- 특정 성분이 고객 개인에게 안전한지, 알러지를 일으키는지 여부는 판단하여 답하지 않는다. 개인별 반응은 다를 수 있으므로 사용 전 패치 테스트를 안내하고, 우려가 큰 경우 전문의 상담을 권유한다.
- "이 제품은 트러블이 절대 없다", "민감성 피부에 100% 안전하다" 등 단정적 표현은 사용하지 않는다.

## 2. 주요 사용 성분 안내

### 2.1 식물성 오일·추출물

- 라벤더 오일: 라벤더 리페어 세럼, 라벤더 에센셜 오일 등에 사용한다. 아로마니카의 대표 향 성분이다.
- 티트리 잎 오일: 티트리 젤 클렌저, 티트리 스팟 케어에 사용한다.
- 캐모마일 추출물: 캐모마일 카밍 토너 등 카밍 라인에 사용한다.
- 로즈힙 오일: 로즈힙 페이스 오일의 주성분이다.
- 시어버터: 시어버터 배리어 크림 등 보습 라인에 사용한다.
- 알로에베라잎 추출물: 알로에 수딩 마스크 등 수딩 라인에 사용한다.
- 카렌듈라꽃 추출물: 카렌듈라 선크림 등에 사용한다.

### 2.2 기능성 성분

- 나이아신아마이드: 브라이트닝 라인에 사용한다. 기능성 화장품 고시 성분으로, 식약처 심사·보고 범위 내의 표현("미백 기능성 화장품")으로만 안내한다.
- 아데노신: 주름 개선 기능성 라인에 사용한다. 동일하게 고시 범위 내 표현으로만 안내한다.
- 히알루론산: 대부분의 보습 라인에 사용한다.
- 판테놀: 배리어 라인에 사용한다.

### 2.3 보존제·기타

- 아로마니카 전 제품은 파라벤류를 사용하지 않는다. 보존제로는 1,2-헥산다이올 등을 사용한다.
- 인공 색소는 전 제품에 사용하지 않는다. 제품의 색은 원료 고유의 색임을 안내한다.
- 향은 에센셜 오일 유래를 원칙으로 하며, 일부 제품에 합성 향료가 포함된 경우 전성분에 "향료"로 표기된다.

## 3. 알러지 유발 가능 성분 안내

### 3.1 착향제 중 알러지 유발 가능 성분(표시 대상)

화장품법령상 표시 대상인 착향제 알러지 유발 성분이 포함된 경우 전성분에 개별 명칭으로 표기한다. 아로마니카 제품에서 확인될 수 있는 대표 성분은 다음과 같다.

- 리날룰(linalool): 라벤더 오일 함유 제품 전반
- 리모넨(limonene): 시트러스 계열 오일 함유 제품
- 제라니올(geraniol): 로즈·제라늄 계열 향 제품
- 시트로넬올(citronellol): 로즈 계열 향 제품
- 유제놀(eugenol): 일부 스파이시 계열 향 제품

### 3.2 알러지 문의 대응 절차

1. 고객이 특정 성분 알러지 이력을 언급하는 경우
   - 해당 성분의 포함 여부를 제품 상세 페이지 전성분 기준으로 확인하여 안내한다.
   - 포함 여부가 확인되지 않는 원료 단위 세부 성분(예: 오일 내 미량 구성 성분)은 품질관리팀 확인 후 회신한다.
2. 사용 후 알러지 반응을 호소하는 경우
   - 사용 중단을 안내하고 ARM-CS-003 §2의 증빙 절차에 따라 트러블 접수를 진행한다.
   - 트러블 인정 시 전액 환불하며 배송비는 회사가 부담한다.
3. 구매 전 안전성 확인을 요청하는 경우
   - 전성분 안내와 패치 테스트 방법 안내까지만 진행하고, 개인별 적합성 판단은 하지 않는다.

### 3.3 패치 테스트 안내 문구

"팔 안쪽 등 부드러운 부위에 소량을 바르고 24~48시간 동안 이상 반응이 없는지 확인 후 사용하시길 권장드립니다. 이상 반응이 나타나면 즉시 사용을 중단하고 전문의와 상담해 주세요."

## 4. 임산부 관련 성분 안내

### 4.1 안내 원칙

- 임신·수유 중 사용 가능 여부를 묻는 문의에는 사용 가능·불가를 단정하지 않고, 아래 참고 정보를 안내한 뒤 최종적으로 전문의(산부인과 등)와 상담 후 사용하도록 권유한다.

### 4.2 임산부 주의 참고 성분

다음 성분 함유 제품은 임신·수유 중 사용에 대해 주의가 필요하다는 일반적 견해가 있어, 문의 시 함유 여부를 확인하여 안내한다.

- 레티놀·레티닐팔미테이트: 안티에이징 인텐시브 라인 2종에 함유
- 살리실산(BHA): 클리어 필링 토너에 함유
- 일부 에센셜 오일(로즈마리, 클라리세이지, 재스민 등): 아로마 블렌딩 오일 3종에 함유
- 고함량 카페인: 아이 리커버 크림에 함유

### 4.3 임산부 문의 조건 분기

1. 함유 제품 구매 전 문의 → 함유 사실과 §4.1의 안내 원칙에 따라 전문의 상담을 권유한다.
2. 함유 제품 구매 후 미개봉 반품 요청 → 임신 사실 인지에 따른 반품은 단순 변심으로 분류하되, 수령 14일 이내 미개봉이면 정상 접수한다(ARM-CS-001 §1.1).
3. 사용 중 이상 반응 문의 → 즉시 사용 중단을 안내하고 전문의 상담을 권유하며, 트러블 접수 절차(ARM-CS-003)를 병행 안내한다.

### 4.4 어린이 사용 문의

- 만 3세 미만 영유아 사용 문의에는 당사 제품이 성인용 화장품 기준으로 개발되었음을 안내하고, 사용 가능 여부를 단정하지 않는다.
- 에센셜 오일 원액 제품은 어린이의 손이 닿지 않는 곳에 보관하도록 안내하고, 원액을 피부에 직접 도포하지 않도록 희석 사용 기준(§4.5)을 함께 안내한다.

### 4.5 에센셜 오일 희석 사용 기준

- 에센셜 오일 원액은 캐리어 오일(호호바, 스위트아몬드 등)에 희석하여 사용하도록 안내한다. 바디 사용 시 1% 이하, 얼굴 사용 시 0.5% 이하 희석을 권장 기준으로 안내한다.
- 희석 비율 예시: 캐리어 오일 10ml 기준 에센셜 오일 2방울이 약 1%에 해당한다.
- 점막, 눈가, 상처 부위 사용은 권장하지 않는다고 안내한다.
- 광독성 우려가 있는 시트러스 계열 오일(베르가못 등)은 도포 후 12시간 이내 직사광선 노출을 피하도록 안내한다.

## 5. 표현 준수 사항

- 의약품으로 오인될 수 있는 표현(치료, 완치, 항염, 아토피 개선 등)은 사용하지 않는다.
- 기능성 화장품은 식약처 심사·보고된 효능 범위 내 표현만 사용한다.
- 타사 제품과의 성분 비교 우위 표현은 사용하지 않는다.
- 성분 안전성에 대한 회사의 공식 입장이 필요한 문의(언론, 단체 등)는 답변하지 않고 홍보팀으로 이관한다.

## 6. 자주 묻는 성분 문의 요약

- "전 제품 비건인가요?" → 비건 인증 라인(카밍 라인 4종)만 인증 완료 상태이며, 그 외 제품은 제품별 상세 페이지 기준으로 안내한다.
- "EWG 등급 알려주세요" → 당사는 EWG 등급을 공식 마케팅에 사용하지 않으므로, 전성분 목록을 안내하고 고객이 직접 확인하도록 안내한다.
- "무향 제품 있나요?" → 무향(향료 무첨가) 라인은 시어버터 배리어 크림 무향 버전 1종이다.
- "알코올(에탄올) 들어가나요?" → 클리어 필링 토너 1종에만 변성알코올이 함유되어 있으며, 그 외 스킨케어 라인은 에탄올 무첨가이다.
- "나이아신아마이드 함량이 몇 %인가요?" → 브라이트닝 세럼은 5%, 브라이트닝 크림은 2% 함유로 안내한다. 그 외 제품의 함량은 비공개 정보이므로 "전성분 표기 순서로 대략적인 함량 순위만 확인 가능하다"고 안내한다.
- "민감성 피부용 추천해 주세요" → 특정 제품이 민감성 피부에 적합하다고 단정하지 않고, 무향·저자극 테스트 완료 라인(카밍 라인)을 소개하되 §3.3의 패치 테스트 안내를 반드시 병행한다.

## 7. 성분 정보 확인 경로

- 1차: 제품 상세 페이지 하단 전성분 목록
- 2차: 제품 용기·단상자 표기
- 3차: 품질관리팀 문의(원료 단위 세부 성분, 함량 등 표기 외 정보)
- 상세 페이지와 용기 표기가 불일치하는 경우 즉시 품질관리팀에 보고하고, 고객에게는 확인 후 회신함을 안내한다. 리뉴얼 제품은 제조 시점에 따라 구성분이 다를 수 있으므로 고객 보유 제품의 용기 표기를 우선 기준으로 안내한다.
