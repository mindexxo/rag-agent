# 아로마니카 정기구독 서비스 안내 (ARM-CS-007)

문서번호: ARM-CS-007 | 시행일: 2026-04-01 | 적용 대상: 아로마니카 온라인몰 정기구독 주문

## 1. 서비스 개요

- 정기구독은 지정한 제품을 4주 또는 8주 주기로 자동 결제·배송하는 서비스이다.
- 구독 대상은 스킨케어 전 품목과 에센셜 오일 단품이며, 선물세트·한정판·샘플은 구독 대상에서 제외한다.
- 1개 구독에 최대 5개 품목까지 담을 수 있으며, 품목별 주기는 동일하게 적용된다.

## 2. 구독 신청

- 신청은 제품 상세 페이지의 "정기구독" 옵션 또는 마이페이지 > 구독 관리에서 가능하다.
- 첫 회차는 신청 즉시 결제·출고되며, 이후 회차는 주기 도래일 오전에 자동 결제된다.
- 자동 결제 실패 시 3일 간격으로 2회 재시도하며, 최종 실패 시 해당 회차는 건너뛰기 처리되고 구독은 유지된다.

## 3. 구독 할인·전용 혜택

- 구독 회차 결제 금액에는 정가 대비 10% 구독 할인을 적용한다.
- 구독 회차 주문은 결제 금액과 무관하게 배송비를 면제한다. 일반 주문의 배송비 기준(기본 2,500원, 30,000원 이상 무료)은 ARM-CS-002 §1을 따르며, 구독 면제는 이보다 우선하는 전용 혜택이다. 단, 도서·산간 추가 배송비 3,000원은 구독 주문에도 부과된다.
- 4회차 결제 완료 시마다 정품 미니어처 1종을 추가 동봉한다. 이는 일반 증정 기준(ARM-CS-006 §2)과 별도로 적용되며, 회차 결제 금액이 30,000원 이상이면 랜덤 샘플 2종 동봉 기준도 동일하게 적용된다.
- 구독 회원 전용 사전 구매(신제품 출시 3일 전) 알림을 제공한다.

## 4. 건너뛰기·주기 변경

- 건너뛰기는 다음 결제 예정일 3일 전까지 마이페이지 또는 상담원 접수로 신청 가능하다.
- 건너뛰기는 연속 2회까지 가능하며, 연속 3회째부터는 해지 의사를 확인한 후 처리한다.
- 배송 주기 변경(4주↔8주)과 품목 변경은 다음 결제 예정일 3일 전까지 가능하며, 이미 결제된 회차에는 소급 적용하지 않는다.
- 결제 예정일 3일 전이 경과한 요청은 해당 회차 출고 후 차회차부터 반영됨을 안내한다.

## 5. 해지

- 해지는 최소 유지 회차 조건 없이 언제든 가능하며, 위약금은 없다.
- 다음 결제 예정일 3일 전까지 해지 접수된 건은 해당 회차부터 결제되지 않는다.
- 해지하더라도 이미 결제·출고된 회차의 반품·환불은 일반 규정과 동일하게 처리한다(§6).
- 해지 후 재신청 시 구독 할인율은 동일하게 적용되나, 미니어처 증정 회차 카운트(§3)는 1회차부터 다시 기산한다.

## 6. 구독 상품의 반품·환불

- 구독 회차 상품도 일반 주문과 동일하게 미개봉 상태에 한하여 수령일로부터 14일 이내 단순 변심 반품이 가능하다(ARM-CS-001 §1.1). 피부 트러블 발생 시 수령일로부터 30일 이내 접수 기준도 동일하다.
- 반품으로 환불되는 금액은 구독 할인이 적용된 실결제 금액 기준으로 한다.
- 자동 결제를 인지하지 못했다는 사유의 환불 요청은, 출고 전이면 전액 취소 처리하고 출고 후에는 일반 반품 절차로 안내한다.

## 7. 상담 시 유의사항

- 건너뛰기와 해지를 혼동하는 문의가 많으므로, 1회만 쉬는 것인지 완전 중단인지 먼저 확인한 후 접수한다.
- 결제 예정일과 마감 시점(3일 전)을 반드시 함께 안내하고, 마감 경과 건은 차회차 반영임을 고지한다.
- 구독 할인율(10%)과 프로모션 할인은 중복 적용되지 않으며, 할인율이 높은 쪽을 자동 적용함을 안내한다.
