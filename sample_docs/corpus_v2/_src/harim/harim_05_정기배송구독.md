# 정기배송(구독) 운영 규정 (HR-CS-005)

문서번호: HR-CS-005 (Rev.1)
적용대상: 하림 직영몰 정기배송 서비스 가입 고객
시행일: 2026-01-02

## 1. 서비스 개요

### 1.1 정기배송 구조
- 배송 주기: 주 1회, 격주, 월 1회 중 선택
- 결제 방식: 회차별 결제일(배송 예정일 2일 전)에 등록 카드로 자동 결제한다.
- 상품 구성: 정기배송 전용 상품 및 일반 상품 중 정기배송 가능 표시가 있는 상품

### 1.2 할인 혜택
정기배송 주문은 회차별 결제 금액에 대해 5% 할인을 적용함을 원칙으로 한다.
- 할인은 상품 금액에만 적용하며, 배송비에는 적용하지 않는다.
- 타 쿠폰과 중복 적용이 가능하되, 중복 적용 시 총 할인율이 상품 금액의 30%를 초과할 수 없다.
- 회차별 결제 금액이 5만원 이상이면 무료배송을 적용하고, 5만원 미만이면 배송비 3,000원을 부과한다(HR-CS-002 §1.1과 동일 기준).

## 2. 회차 변경·건너뛰기

### 2.1 변경 가능 기한
배송 예정일 3일 전 자정까지 다음 항목을 마이페이지 또는 상담원을 통해 변경할 수 있다.
- 상품 구성·수량 변경
- 배송 주기·배송지 변경
- 해당 회차 건너뛰기

### 2.2 건너뛰기 규정
- 건너뛰기는 연속 3회까지 허용한다. 연속 4회 이상 건너뛰기를 요청하는 경우 구독 일시정지로 전환하도록 안내한다.
- 일시정지는 최대 60일까지 가능하며, 60일 경과 시 구독이 자동 해지된다. 자동 해지 7일 전 알림 문자를 발송한다.
- 건너뛴 회차는 결제되지 않으며, 할인 혜택·회차 적립에도 산입하지 않는다.

### 2.3 결제 실패 처리
회차 결제 실패 시 다음 날 오전 1회 재시도한다. 재시도 실패 시 해당 회차는 자동 건너뛰기 처리하며, 결제 실패가 연속 2회차 발생하면 구독을 일시정지 상태로 전환하고 고객에게 안내 문자를 발송한다.

## 3. 해지

### 3.1 해지 신청
- 해지는 위약금 없이 언제든지 가능하다.
- 배송 예정일 3일 전 자정 이전 신청: 다음 회차부터 즉시 해지 적용
- 배송 예정일 3일 전 자정 이후 신청: 이미 결제·출고 준비된 해당 회차는 정상 배송되고, 그다음 회차부터 해지 적용
- 이미 결제된 회차의 취소를 함께 요청하는 경우, 출고 전이면 결제 취소를 처리하고 출고 후이면 신선식품 반품 불가 원칙(HR-CS-001 §1.1)에 따라 취소가 불가함을 안내한다.

### 3.2 해지 후 재가입
해지 후 재가입에 제한은 없다. 단, 재가입 시 기존 회차 실적은 승계되지 않으며 신규 가입 기준이 적용된다.

## 4. 상담원 응대 지침

### 4.1 자주 접수되는 문의 응대
- "이번 주만 안 받고 싶다": 건너뛰기(§2.2)를 안내한다. 해지가 아닌 건너뛰기로 처리하면 할인 혜택이 유지됨을 함께 안내한다.
- "할인이 왜 5%보다 적게 됐냐": 할인이 상품 금액 기준이며 배송비 제외라는 점(§1.2)을 확인한다.
- "결제됐는데 취소하고 싶다": 출고 여부를 먼저 확인하고 §3.1 분기에 따라 처리한다.

### 4.2 가입·변경 처리 시 확인 사항
1. 구독 상태(정상 / 일시정지 / 해지 예약)를 먼저 조회한다.
2. 변경 요청이 배송 예정일 3일 전 자정 이전인지 확인한다. 마감 경과 건은 해당 회차에 반영이 불가하며 다음 회차부터 적용됨을 안내한다.
3. 결제 카드 변경 요청은 본인 확인 후 마이페이지 등록 절차를 안내하며, 상담원이 카드 정보를 직접 수집하지 않는다.

### 4.3 유의사항
- 정기배송 상품의 품질 이상은 일반 주문과 동일하게 수령 후 24시간 이내 신고 원칙 및 재배송·환불 고객 선택 기준을 적용한다(HR-CS-003 참조).
- 회차 변경 마감(배송 예정일 3일 전 자정)이 임박한 문의는 마감 시각을 명시하여 안내한다.
