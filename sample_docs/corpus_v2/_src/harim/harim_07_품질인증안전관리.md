# 품질 인증·안전 관리 안내 규정 (HR-CS-007)

문서번호: HR-CS-007 (Rev.1)
적용대상: 하림 직영몰 판매 전 품목군
시행일: 2026-01-02

## 1. 인증 안내 기준

### 1.1 HACCP 인증
직영몰 판매 육류 및 가공품은 HACCP(식품안전관리인증) 인증 사업장에서 생산됨을 원칙으로 한다.
- 인증 여부는 상품 포장의 HACCP 마크로 확인할 수 있으며, 상담원은 고객 문의 시 포장 표시면 확인을 안내한다.
- 고객이 인증서 사본을 요청하는 경우 직영몰 상품 상세 페이지의 인증 정보 게시 위치를 안내하고, 게시되지 않은 품목은 품질보증팀에 확인 후 회신한다.
- HACCP 인증은 사업장(공장) 단위 인증이므로 "전 상품 무항생제"와 같은 다른 인증과 혼동하여 안내하지 않는다.

### 1.2 무항생제 인증
- 무항생제 인증은 해당 표시가 있는 품목에 한하여 적용되며, 전 품목 대상이 아니다.
- 인증 품목은 포장에 무항생제 인증 마크와 인증번호가 표기된다. 상담원은 품목별 인증 여부를 상품 상세 페이지 기준으로 확인하여 안내한다.
- 무항생제 여부를 확답하기 어려운 품목은 임의로 안내하지 않고 품질보증팀 확인 후 회신한다.

## 2. 이력추적번호 조회 응대

### 2.1 이력번호 표기
닭고기 상품에는 포장에 이력추적번호(12자리)가 표기된다. 이력번호로 사육 농장, 도계 일자, 도계장 정보를 조회할 수 있다.

### 2.2 조회 문의 응대 순서
1. 포장 표시면의 이력번호 위치를 안내한다(유통기한 표시 인근).
2. 축산물 이력 조회 사이트 또는 직영몰 상품 페이지의 이력 조회 메뉴 이용 방법을 안내한다.
3. 조회 결과가 표시 내용과 다르다는 문의(농장·일자 불일치 등)는 상담원이 판단하지 않고 이력번호와 함께 품질보증팀으로 이관한다.
4. 포장 훼손으로 이력번호 확인이 불가한 경우, 주문번호 기준으로 출고 로트를 조회하여 회신할 수 있음을 안내하고 품질보증팀에 조회를 의뢰한다.

## 3. 원산지 표시 기준

### 3.1 표시 원칙
- 닭고기 원료육은 국내산 사용을 원칙으로 하며, 포장 및 상품 페이지에 원산지를 표시한다.
- 가공품은 주원료(닭고기) 원산지를 표시하며, 부원료 원산지는 상품 상세 페이지의 표시 사항을 기준으로 안내한다.
- 개별 상품의 표시 사항이 본 규정 안내와 다른 경우 상품 포장의 표시 사항을 우선한다(HR-CS-004 §1.1과 동일 원칙).

### 3.2 원산지 관련 문의 응대
- "원산지가 표시와 다른 것 같다"는 문의는 근거(포장 사진)를 접수하고 품질보증팀으로 이관하며, 상담원 선에서 표시 오류 여부를 확답하지 않는다.
- 원산지 관련 불만이 품질 이상 주장(변질 등)과 함께 접수되는 경우 품질 이상 건은 수령 후 24시간 이내 신고 원칙(HR-CS-003 §1.1)에 따라 별도 접수한다.

## 4. 상담원 응대 지침

### 4.1 안내 범위
- 상담원이 직접 안내 가능한 범위: 인증 마크·이력번호·원산지 표시의 확인 위치, 조회 방법
- 품질보증팀 이관 대상: 인증 유효성 판단, 이력 조회 결과 불일치, 원산지 표시 오류 주장

### 4.2 기록
인증·이력·원산지 관련 문의는 상담 시스템에 "인증/이력" 카테고리로 기록하고, 확인된 이력번호 또는 로트번호를 함께 기재한다(HR-CS-003 §5.4의 기록 의무와 동일 기준).
