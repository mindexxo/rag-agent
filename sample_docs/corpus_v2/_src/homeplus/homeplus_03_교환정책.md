# 교환 정책 (HP-CS-003)

문서번호: HP-CS-003 | 시행일: 2026-03-02 | 관리부서: 고객서비스운영팀

## 1. 교환 접수 기준

교환은 반품과 동일하게 상품 수령일로부터 30일 이내 접수를 원칙으로 한다(HP-CS-001 §2 참조). 신선식품은 교환 대신 품질보증 규정(HP-CS-004)에 따른 환불로 처리한다.

## 2. 교환 유형별 처리

### 2.1 동일 상품 교환
색상·사이즈 등 동일 상품 내 옵션 교환은 재고 확인 후 접수한다. 교환 사유가 단순변심이면 왕복 배송비 6,000원을 고객이 부담하고, 상품 하자·오배송이면 회사가 전액 부담한다.

### 2.2 다른 상품으로 교환
다른 상품으로의 교환은 지원하지 않는다. 반품 환불 후 재주문을 안내한다.

### 2.3 재고 소진 시
교환 요청 상품의 재고가 소진된 경우 환불로 전환 처리하며, 하자 사유였다면 홈플 포인트 2,000점을 추가 지급한다.

## 3. 교환 절차

1. 상담원이 교환 사유·사진 증빙 확인 후 접수 등록
2. 택배사 회수 지시(회수 예정일 안내, 통상 접수 후 1~2영업일 내 방문)
3. 회수 상품 검수 완료 후 교환 상품 출고 (검수 완료로부터 2영업일 이내)
4. 검수에서 사용 흔적이 확인되면 교환을 중단하고 고객에게 반송한다. 반송 배송비 3,000원은 고객이 부담한다.

## 4. 가격 차액 처리

교환 시점의 판매가가 주문 시점보다 인상된 경우 차액을 청구하지 않고 주문 시점 가격을 유지한다. 반대로 판매가가 인하된 경우에도 차액을 환급하지 않는다. 단, 하자·오배송 사유의 교환에서 재고 소진으로 상위 옵션 상품을 대체 제공하는 경우에는 차액을 회사가 부담한다.

## 5. 상담원 유의사항

- 교환 상품 출고는 회수 검수 완료를 선행 조건으로 하며, 선출고는 CS리더 승인 건에 한한다.
- 하자 주장 건은 사진 증빙 없이는 무상 교환으로 접수하지 않는다. 증빙 제출을 거부하는 경우 단순변심 기준으로 안내한다.
- 교환 접수 후 고객이 환불로 변경을 요청하면 회수 검수 전까지는 환불로 전환할 수 있고, 교환 상품이 이미 출고된 후이면 교환 상품 수령 후 별도 반품 절차로 안내한다.
