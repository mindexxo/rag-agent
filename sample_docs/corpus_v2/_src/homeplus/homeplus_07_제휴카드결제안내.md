# 제휴카드·결제 안내 (HP-CS-007)

문서번호: HP-CS-007 | 시행일: 2026-03-02 | 관리부서: 결제정산팀

## 1. 적용 범위

본 규정은 홈플러스 온라인몰의 제휴 신용카드 혜택, 무이자 할부, 결제 수단별 환불 경로에 대한 상담 기준을 정한다. 환불 처리 기한의 일반 원칙은 HP-CS-001 §4.1을 따른다.

## 2. 제휴카드 혜택

### 2.1 즉시 할인
홈플 제휴 신용카드로 결제하면 결제 금액의 5%를 즉시 할인한다. 즉시 할인의 한도는 1회 주문당 최대 5,000원, 월 누계 최대 20,000원으로 한다. 할인 한도 소진 여부는 카드사 시스템 기준이므로 상담원이 임의로 잔여 한도를 확정 안내하지 않는다.

### 2.2 추가 적립
제휴카드 결제 건은 기본 적립률에 0.5%p를 추가 적립하며, 적립 지연 문의 응대는 HP-CS-005 §5.1의 기준(카드사 정산 주기에 따라 최대 15일 지연 가능)을 따른다.

### 2.3 혜택 중복 기준
즉시 할인과 추가 적립은 중복 적용된다. 단, 즉시 할인이 적용된 금액은 실결제 금액 기준으로 적립·등급 실적에 산정된다.

## 3. 무이자 할부

### 3.1 적용 기준
- 제휴카드: 5만원 이상 결제 시 2~6개월 무이자 할부
- 일반 신용카드: 5만원 이상 결제 시 2~3개월 무이자 할부 (카드사별 행사 기준)
- 무이자 할부 적용 건은 카드사 포인트 적립 대상에서 제외될 수 있음을 고지한다.

### 3.2 부분 취소 시 할부 처리
할부 결제 건을 부분 취소하면 취소 금액은 카드사 기준에 따라 잔여 할부금에서 차감되거나 일시 환급된다. 차감 방식은 카드사마다 다르므로 상담원은 "카드사 확인 필요"로 안내하고 확정 답변하지 않는다.

## 4. 결제 수단별 환불 경로

| 결제 수단 | 환불 경로 | 처리 기한 |
|---|---|---|
| 신용카드(일시불·할부) | 승인 취소 | 검수 완료 후 3영업일 이내 |
| 계좌이체·가상계좌 | 환불 계좌 입금 | 검수 완료 후 2영업일 이내 |
| 홈플 포인트 | 포인트 복원 | 검수 완료 즉시 |
| 간편결제(홈플페이) | 원결제 수단 취소 | 간편결제사 기준 3~5영업일 |
| 휴대폰 결제 | 당월: 승인 취소 / 익월 이후: 계좌 환불 | 당월 즉시 / 익월 5영업일 이내 |

### 4.1 복합 결제 환불
포인트와 카드를 함께 사용한 주문의 부분 환불은 포인트 사용분을 우선 복원하고 잔액을 카드 취소로 처리한다. 고객이 순서 변경을 요구해도 시스템상 변경할 수 없음을 안내한다.

### 4.2 휴대폰 결제 익월 환불
휴대폰 결제의 익월 이후 환불은 고객의 환불 계좌 등록이 선행되어야 한다. 계좌 미등록 상태의 환불 지연 문의는 계좌 등록 안내를 먼저 진행한다.

## 5. 카드 승인 취소 지연 응대

승인 취소 후 카드사 반영까지 영업일 기준 최대 7일이 소요될 수 있다(HP-CS-001 §8). 취소 전표 확인을 요청하는 고객에게는 앱 주문 상세의 취소 접수 내역을 안내하고, 카드사 미반영 분쟁이 지속되면 정산팀에 이관한다.

## 6. 상담원 유의사항

- 제휴카드 신규 발급 상담은 카드사 고객센터로 안내하며 상담 채널에서 발급 접수를 대행하지 않는다.
- 즉시 할인 미적용 주장 건은 결제 시점의 한도 소진 여부가 원인인 경우가 많으므로 §2.1의 한도 기준을 먼저 안내한다.
- 무이자 할부 개월 수 변경은 결제 완료 후 불가하며, 취소 후 재주문으로만 가능함을 안내한다.
