# 정품 등록·리콜 대응 기준 (SUM-CS-007)

문서번호: SUM-CS-007 | 제정: 2025-02-10 | 최종 개정: 2025-12-01 | 적용 대상: 써머스코리아 전 제품

## 1. 목적

본 문서는 정품 등록 서비스의 접수·혜택 안내 기준과, 리콜 발생 시 상담 대응 절차를 정한다. 리콜의 판정·보상 원칙은 SUM-CS-004 §6을 따르며, 본 문서는 상담 창구에서의 실행 절차를 규정한다.

## 2. 정품 등록

### 2.1 등록 방법

- 공식몰 마이페이지의 정품 등록 메뉴에서 제품 바닥면 로트 번호와 구매일을 입력하여 등록한다.
- 대리점·오픈마켓 구매 고객은 구매 영수증 사진을 첨부하여 등록한다. 영수증 확인은 2영업일 이내 완료한다.
- 선물 수령 고객은 구매자 주문번호 없이도 로트 번호만으로 등록 가능하며, 이 경우 보증기간 기산은 SUM-CS-004 §1의 제조일 기준을 적용한다.

### 2.2 등록 기한

구매일(또는 수령일)로부터 90일 이내 등록 건에 한해 혜택을 적용한다. 90일 경과 후에도 등록 자체는 가능하나 §2.3의 혜택은 적용하지 않고 리콜 통지 대상에만 포함한다.

### 2.3 등록 혜택

- 적립금 2,000원을 등록 완료 즉시 지급한다.
- 소모품(패킹·빨대·손잡이) 20% 할인 쿠폰을 연 1회 발급한다. 할인 대상 부품가는 SUM-CS-004 §2의 유상 판매가를 기준으로 한다.
- 리콜·안전 관련 공지를 문자로 우선 통지한다.
- AS 접수 시 등록 정보의 구매일을 구매 증빙으로 인정하여 별도 영수증 제출을 생략한다.

정품 등록이 보증기간 자체를 연장하지는 않는다. 부품별 보증기간은 SUM-CS-004 §2를 그대로 적용한다.

## 3. 리콜 발생 시 상담 대응 절차

### 3.1 대상 확인

- 리콜 공지가 게시되면 상담 시스템 공지 배너에 대상 모델명과 로트 번호 범위가 등록된다. 상담원은 고객이 불러주는 제품 바닥면 로트 번호를 시스템에 조회하여 대상 여부를 즉시 확인한다.
- 로트 번호 확인이 어려운 고객(각인 마모 등)은 구매 시기와 모델명으로 잠정 대상 처리 후 회수 검수 단계에서 최종 판정한다.

### 3.2 상담 흐름

1. 대상 확인 → 2. 사용 중지 안내 → 3. 무상 교환 또는 전액 환불 중 고객 선택 접수 → 4. 회수 접수 → 5. 처리 완료 문자 발송 순으로 진행한다.

- 대상 확인 즉시 해당 제품의 사용 중지를 안내한다. 안전 관련 결함 리콜은 증상 유무와 무관하게 회수한다.
- 교환·환불 처리와 회수·재배송 배송비는 SUM-CS-004 §6에 따라 보증기간과 무관하게 전액 회사가 부담한다.
- 리콜 대상 제품의 일반 AS·반품 문의가 인입되면 리콜 절차로 전환하여 처리한다.

### 3.3 비대상 고객 응대

로트 번호 조회 결과 비대상으로 확인되면 비대상 사유(로트 범위 외)를 안내하고, 불안을 호소하는 고객에게는 SUM-CS-004 §3의 표준 테스트 절차를 안내한다. 비대상 건의 교환·환불 요구는 일반 규정(SUM-CS-001, SUM-CS-003)을 적용한다.

## 4. 상담원 처리 지침

- 리콜 상담은 사과 표현을 먼저 하고 절차를 안내한다. 원인·범위에 대한 추측성 답변을 하지 않으며, 공지문 기재 내용만 안내한다.
- 리콜 접수 건은 상담 이력에 리콜 코드와 로트 번호를 필수 기록한다.
- 정품 등록 여부와 무관하게 리콜 보상은 동일하게 적용됨을 안내한다. 미등록 고객에게는 처리 완료 후 정품 등록을 권유한다.
- 언론 보도 등 공지 게시 전 리콜 문의가 인입되면 확인 후 회신을 약속하고 CS팀장에게 즉시 보고한다.
