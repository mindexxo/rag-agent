# 아로마니카 샘플·증정품 정책 (ARM-CS-006)

문서번호: ARM-CS-006 | 시행일: 2026-01-02 | 적용 대상: 아로마니카 온라인몰 샘플·증정품·사은품

## 1. 기본 원칙

- 샘플과 증정품은 판매 상품이 아니며, 환불·교환·반품의 대상이 아니다.
- 샘플·증정품 자체의 하자(누액, 파손 등)는 재발송으로만 처리하며 금전 보상은 하지 않는다.
- 샘플·증정품 사용 후 피부 이상이 발생한 경우에는 판매 상품과 동일하게 트러블 접수(ARM-CS-003)를 진행한다. 단, 샘플·증정품은 결제 금액이 없으므로 환불이 아닌 사용 중단 안내와 품질 이관으로 처리한다.

## 2. 증정 기준

- 전 주문 공통: 30,000원 이상 구매 시 랜덤 샘플 2종을 동봉한다.
- 50,000원 이상 구매 시 미니어처 증정품 1종을 추가 동봉한다.
- 프로모션별 증정 기준은 프로모션 페이지 고지 내용을 우선 적용한다.
- 샘플 종류 지정 요청은 주문 메모에 기재된 경우에 한하여 재고 범위 내에서 반영하며, 반영을 보장하지는 않는다.

## 3. 반품 시 증정품 처리 조건 분기

1. 주문 전체를 반품하는 경우
   - 증정품·샘플을 미개봉 상태로 함께 반환하여야 한다.
   - 증정품을 반환하지 않거나 개봉·사용한 경우, 증정품 정상가(상세 페이지 고지 가격)를 환불 금액에서 차감한다. 랜덤 샘플은 차감 대상에서 제외한다.
2. 부분 반품으로 잔여 결제 금액이 증정 기준에 미달하는 경우
   - 예: 반품 후 잔여 금액이 50,000원 미만이 되면 미니어처 증정품 반환 대상이 된다.
   - 반환하지 않는 경우 1항과 동일하게 정상가를 차감한다.
3. 트러블 사유 환불(ARM-CS-001 §1.2)인 경우
   - 사용한 증정품·샘플의 차감 없이 전액 환불을 원칙으로 한다.

## 4. 샘플 관련 문의 대응

- "샘플이 안 왔어요": 출고 검수 기록 확인 후 누락 확인 시 익영업일에 재발송한다. 재발송 배송비는 회사가 부담한다.
- "샘플만 따로 구매할 수 있나요": 샘플 단독 판매는 하지 않음을 안내한다.
- "증정품이 파손됐어요": 사진 접수 후 동일 증정품 재발송을 원칙으로 하되, 재고 소진 시 동급 대체품을 안내한다.
- 샘플 사용 후 본품 구매 문의: 별도 혜택은 없으며 일반 구매 절차를 안내한다.

## 5. 유의사항

- 증정품에도 유통기한이 표기되며, 보관 기준은 ARM-CS-004 §3을 동일하게 적용한다.
- 증정품 재고 소진 시 사전 고지 없이 동급 대체품으로 변경될 수 있음을 안내한다.
