굿피플 후원자 상담 상황별 응대 스크립트 (GP-CS-008)
문서번호: GP-CS-008 / 개정일: 2026-01-05 / 적용 대상: 후원자 상담 전 채널

[상황 1] 정기후원 해지 요청
1. "후원을 중단하고 싶으시군요. 먼저 본인 확인을 도와드리겠습니다."
2. 본인 확인 후 해지 사유를 청취한다. 사유 청취가 해지 처리를 지연시키지 않도록 한다.
3. 경제적 사정이 사유인 경우 1회에 한해 안내한다. "해지 대신 최대 6개월간 출금을 일시 중지하는 방법도 있습니다. 중지 기간이 끝나면 출금이 자동 재개되는 점은 미리 말씀드립니다."
4. 해지 의사를 재확인하면 즉시 접수한다. "해지 접수가 완료되었습니다. 확인 문자를 보내드리겠습니다."
5. 출금일 3영업일 전 이후 접수 건은 안내한다. "이번 달 출금은 정상 진행되고 다음 달부터 해지가 적용됩니다. 이번 달 출금분은 환불 대상이 아닌 점 양해 부탁드립니다."

[상황 2] 이중 출금 항의
1. "같은 회차가 두 번 출금되어 놀라셨겠습니다. 죄송합니다. 바로 확인해 드리겠습니다."
2. 출금 이력에서 동일 회차 중복 출금 여부를 확인한다.
3. 이중 출금이 확인되면 별도 확인 절차 없이 즉시 환불 접수를 등록한다.
4. "중복 출금된 금액 전액을 접수일로부터 5영업일 이내에 출금하신 계좌(또는 카드 취소)로 환불해 드리겠습니다."
5. 이미 영수증이 발급된 건이면 수정 발급이 함께 처리됨을 안내한다.

[상황 3] 기부금영수증 미발급(간소화 미조회) 문의
1. "연말정산 간소화에서 기부 내역이 조회되지 않으시는군요. 확인해 드리겠습니다."
2. 본인 확인 후 주민등록번호 등록 여부를 확인한다.
3. 미등록이 원인인 경우 안내한다. "주민등록번호가 등록되어 있지 않아 자동 등록에서 제외되었습니다. 지금 등록해 주시면 내년 간소화부터 반영되고, 올해분은 개별 발급으로 바로 도와드리겠습니다."
4. 전자 발급은 즉시, 우편 발급은 접수일로부터 7일 이내 등기 발송을 안내한다.
5. 공제 금액이나 공제율 문의에는 답하지 않는다. "공제 적용 여부는 국세청(국번 없이 126)이나 관할 세무서에서 확인하실 수 있습니다."

[상황 4] 결연 아동 안부 문의
1. "결연 아동의 근황이 궁금하시군요. 본인 확인 후 안내해 드리겠습니다."
2. 최근 성장보고서 발송 이력을 확인한다. 성장보고서는 연 1회, 결연 개시월 기준으로 발송된다.
3. 미수신인 경우 재발송을 접수한다. "전자 발송은 바로, 우편은 7일 이내에 다시 보내드리겠습니다."
4. 편지를 보내신 경우 답장은 연 1회 이상 제공되며 지역 사정에 따라 지연될 수 있음을 안내한다.
5. 아동의 정확한 거주지, 가족 연락처 등 구체적 신상 정보는 어떠한 경우에도 안내하지 않는다.

[상황 5] 후원금 사용처 불신 표현
1. "소중한 후원금이 어떻게 쓰이는지 궁금해하시는 것은 당연합니다."
2. 반박하지 않고 후원 유형(일반/지정기부/결연)을 먼저 확인한다.
3. 연차보고서와 홈페이지 공시 자료실의 결산·외부 회계감사 보고서 조회 방법을 안내한다.
4. 지정기부는 해당 캠페인의 집행 보고(종료 후 3개월 이내 공개)를 기준으로 안내한다.
5. 개인 후원금 단위의 사용처 추적은 통합 회계 구조상 제공되지 않음을 설명한다.

[상황 6] 착오 출금(금액 상이) 문의
1. "신청하신 금액과 다르게 출금되었군요. 불편을 드려 죄송합니다."
2. 신청 금액과 실제 출금액을 대조한다.
3. 초과 출금이면 차액 전액 환불을 접수한다. "차액은 접수일로부터 5영업일 이내에 환불됩니다."
4. 과소 출금이면 추가 출금 여부를 여쭙는다. "부족분을 추가 출금할지, 이번 회차는 그대로 둘지 선택하실 수 있습니다."

[상황 7] 후원 금액·결제일 변경 요청
1. 본인 확인 후 즉시 처리한다. 별도 서류는 필요하지 않다.
2. "출금일 3영업일 전까지 접수되면 이번 달부터, 그 이후면 다음 달부터 변경 금액이 적용됩니다."
3. 결제일 변경 시 같은 달에 2회 출금되지 않도록 자동 조정되며, 조정 결과는 문자로 안내됨을 고지한다.
4. 결연 후원은 월 45,000원 정액으로 금액 변경이 불가함을 안내한다.

[상황 8] 미납 회차 소급 출금 문의
1. 출금 실패 이력과 미납 회차를 확인한다.
2. "미납된 회차는 요청하지 않으시면 출금되지 않습니다. 원하시면 소급 출금을 접수해 드리겠습니다."
3. 3회 연속 미납으로 출금이 일시 중지된 경우, 재개 의사를 확인하고 결제수단 상태(카드 유효기간 등)를 함께 점검한다.
