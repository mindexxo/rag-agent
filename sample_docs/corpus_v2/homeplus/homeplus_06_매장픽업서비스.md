# 매장 픽업 서비스 (HP-CS-006)

문서번호: HP-CS-006 | 시행일: 2026-03-02 | 관리부서: 옴니채널운영팀

## 1. 서비스 개요

매장 픽업은 온라인몰에서 주문한 상품을 고객이 지정한 매장에서 직접 수령하는 서비스다. 픽업 주문은 주문금액과 관계없이 배송비를 부과하지 않는다.

## 2. 주문 및 수령 기준

### 2.1 픽업 가능 시간
- 당일 11시까지 주문: 당일 16시 이후 수령 가능
- 당일 11시 이후 주문: 익일 11시 이후 수령 가능
- 수령 가능 시간은 매장 영업시간(10시~22시) 내로 한정한다.

### 2.2 수령 절차
고객은 픽업 카운터에서 주문번호와 본인 확인 후 상품을 수령한다. 대리 수령은 주문자가 앱에서 대리인을 사전 지정한 경우에 한하여 허용한다.

### 2.3 보관 기한
상품은 픽업 가능 시점부터 3일간 보관한다. 3일 내 미수령 시 주문은 자동 취소되며, 일반 상품이면 전액 환불하고 신선식품이면 폐기 후 상품가의 50%만 환불한다. 상담원은 보관 만료 전일 고객에게 안내 아웃바운드를 시도한다.

## 3. 픽업 주문의 취소·변경

- 매장 상품 준비 시작 전(주문 상태 '결제완료')이면 앱 또는 상담원이 취소할 수 있다.
- 준비 완료 후에는 취소 대신 미수령 자동 취소 절차(§2.3)를 안내한다.
- 픽업 매장 변경은 지원하지 않으며 취소 후 재주문을 안내한다.

## 4. 픽업 상품의 반품

픽업 수령 상품의 반품은 수령 매장 지참 반품과 택배 반품 중 고객이 선택할 수 있다. 매장 지참 반품이면 배송비 없이 즉시 검수·환불하고, 택배 반품이면 HP-CS-001 §3의 배송비 부담 기준을 동일하게 적용한다. 접수 기간은 일반 반품과 동일하게 수령일로부터 30일이다. 픽업 수령 신선식품의 품질 이의제기는 HP-CS-004와 동일하게 수령 후 7일 이내 접수하며, 매장 수령 시점에 고객이 현장 검수 후 수령을 거부한 상품은 즉시 전액 환불한다.

## 5. 상담원 유의사항

- 픽업 준비 완료 알림 발송 후에도 앱 알림 미확인 고객이 있으므로, 미수령 문의 시 알림 발송 이력을 먼저 확인한다.
- 대리 수령 관련 분쟁(사전 지정 없는 가족 수령 요구 등)은 예외 승인 없이 §2.2 기준으로만 안내한다.
- 픽업 주문에는 배송비가 없으므로 무료배송 기준(4만원) 관련 안내를 하지 않는다.
