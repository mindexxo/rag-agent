상담 스크립트 모음 (HP-CS-008)
문서번호: HP-CS-008 | 시행일: 2026-03-02 | 관리부서: 고객서비스운영팀

본 문서는 자주 접수되는 상황별 표준 응대 스크립트를 정리한 것이다. 스크립트는 안내 골격이며, 세부 기준은 각 규정 문서(HP-CS-001~007)를 따른다.

[상황 1] 신선식품 품질 불만
1. "불편을 드려 죄송합니다. 신선식품은 사유와 관계없이 100% 환불해 드리고 있습니다."
2. "확인을 위해 상품 상태 사진을 앱 채팅으로 보내주시겠어요?"
3. 사진 확인 후: "확인되었습니다. 회수 없이 오늘 중으로 환불 등록해 드리겠습니다."
4. "포인트로 환불받으시면 5%를 더해 드리는데, 어느 쪽으로 도와드릴까요?"
5. 수령 후 7일이 지난 건은 접수 불가 사유를 안내하고 양해를 구한다.

[상황 2] 배송 누락(미수령) 주장
1. "먼저 배송 완료 사진을 확인해 드리겠습니다. 잠시만 기다려 주세요."
2. 사진상 정상 배송이면: "문 앞 사진이 확인되는데, 혹시 경비실이나 공동현관을 한번 확인해 주시겠어요?"
3. 확인 불가 시: "물류팀 조사를 접수해 드리겠습니다. 영업일 기준 2일 내에 재배송 또는 환불로 안내드리겠습니다."
4. 조사 기간 중 중간 안내 1회 이상을 반드시 실시한다.

[상황 3] 포인트 소멸 항의
1. "확인해 보니 해당 포인트는 유효기간이 지나 소멸된 건입니다."
2. "소멸 30일 전과 7일 전에 앱 푸시로 안내드렸던 점 양해 부탁드립니다."
3. "소멸된 포인트는 규정상 복원이 어렵습니다. 다만 시스템 오류로 소멸된 경우에는 확인 후 복원해 드립니다."
4. 시스템 오류 주장 건은 멤버십운영팀 확인 후 회신하며, 상담원이 즉석에서 복원을 약속하지 않는다.

[상황 4] 새벽배송 주문 취소 요청
1. "새벽배송 주문은 전날 밤 11시까지만 취소가 가능합니다."
2. 컷오프 이전이면: "지금 바로 취소 도와드리겠습니다. 환불은 결제 수단에 따라 처리됩니다."
3. 컷오프 이후이면: "이미 배송 편성이 완료되어 취소가 어렵습니다. 수령 후 반품으로 도와드릴 수 있습니다."

[상황 5] 반품 기간 경과 문의
1. "반품은 상품을 받으신 날로부터 30일 이내에 접수해 드리고 있습니다."
2. "확인해 보니 수령일이 30일을 지나 접수가 어렵습니다. 양해 부탁드립니다."
3. 고객이 하자를 주장하며 이의를 지속하면 CS리더에게 에스컬레이션한다.

[상황 6] 배송 지연 보상 요구
1. "약속드린 시간보다 늦어져 죄송합니다. 지연 시간을 먼저 확인하겠습니다."
2. 당일·새벽배송 2시간 초과 지연이면: "보상으로 홈플 포인트 3,000점을 지급해 드리겠습니다."
3. 일반배송 3일 이상 지연이면 2,000점을 지급한다.
4. 상한 이상의 실손 보상 요구는 물류운영팀 이관으로 안내한다.

[상황 7] 픽업 상품 미수령 문의
1. "픽업 상품은 준비 완료 후 3일간 보관되며, 기한이 지나면 자동 취소됩니다."
2. 일반 상품이면: "자동 취소 시 전액 환불되니 걱정하지 않으셔도 됩니다."
3. 신선식품이면: "신선식품은 폐기 후 상품가의 50%만 환불되는 점을 꼭 안내드립니다."
4. 보관 만료 전일에는 안내 아웃바운드를 시도하고 이력을 남긴다.

[상황 8] 제휴카드 즉시 할인 미적용 문의
1. "제휴카드 즉시 할인은 1회 최대 5,000원, 월 최대 20,000원까지 적용됩니다."
2. "이번 결제에 할인이 빠진 것은 월 한도 소진 때문일 가능성이 높습니다."
3. "정확한 잔여 한도는 카드사에서 확인하실 수 있도록 카드사 고객센터를 안내드리겠습니다."
