써머스코리아 고객센터 상황별 응대 스크립트 모음
문서번호 SUM-CS-008 / 제정 2025-04-15 / 최종 개정 2025-12-01
용도: 신입 상담원 교육 및 실상담 참고용. 문구는 상황에 맞게 조정하되 안내 수치는 규정 문서를 따른다.


[상황 1] 보온이 안 된다는 문의

1. "불편을 드려 죄송합니다. 몇 가지 사용 환경을 먼저 확인해 드리겠습니다."
2. 예열 여부, 음료량(병목 아래 1cm까지 채웠는지), 뚜껑 체결 상태, 패킹 사용 기간(6개월 이상 여부)을 순서대로 확인한다.
3. 해당 원인이 있으면: "말씀하신 사용 환경에서는 보온 시간이 짧아질 수 있습니다. 뜨거운 물로 1분 정도 예열하신 후 병목 아래 1cm까지 채워서 사용해 보시겠어요?"
4. 원인이 없으면: "끓는 물을 채우고 6시간 후 온도를 확인하는 표준 테스트를 안내드리겠습니다. 기준에 미달하면 무상 AS로 접수해 드립니다."
5. 본체 표면 전체가 차갑고 물방울이 맺힌다고 하면 테스트 없이 바로 AS 접수로 전환한다.

[상황 2] 배송 지연 항의

1. "배송이 늦어져 불편을 드려 죄송합니다. 주문번호 확인 후 배송 상태를 바로 조회해 드리겠습니다."
2. 출고일 기준 5일(도서산간 8일) 경과 여부를 확인한다.
3. 회사 귀책(출고 누락 등)이면: "저희 출고 과정의 문제로 확인되었습니다. 적립금 3,000원을 지급해 드리고 바로 출고 처리하겠습니다."
4. 택배사 구간 지연이면: "택배사에 확인 요청을 넣었습니다. 재출고와 환불 중 원하시는 방법으로 처리해 드리겠습니다."
5. 처리 방법과 예상 일정을 문자로 재안내한다.

[상황 3] 각인 오타 클레임

1. "각인 문구에 문제가 있어 속상하셨겠습니다. 주문서에 입력하신 문구와 실제 각인을 대조해 확인하겠습니다."
2. 주문서와 다르게 각인된 경우: "저희 제작 과정의 오류입니다. 무상으로 재제작해 드리거나 전액 환불해 드리겠습니다. 어느 쪽으로 진행할까요?"
3. 주문서에 입력된 문구 그대로 각인된 경우: "주문 시 입력하신 문구와 동일하게 제작되어 재제작이나 환불 처리가 어렵습니다. 양해 부탁드립니다."
4. 재제작 선택 시 제작 기간 5~7영업일을 안내하고, 문구 철자를 복창하여 확인한다.

[상황 4] 단순변심 반품 배송비 안내

1. "수령일로부터 14일 이내이므로 반품 접수가 가능합니다."
2. "단순변심 반품은 왕복 배송비 6,000원을 부담하셔야 합니다. 환불금에서 차감할까요, 아니면 상자에 동봉하시겠어요?"
3. 음료를 담아 사용한 흔적이 있으면 반품이 어려움을 접수 전에 미리 안내한다.
4. 무료배송으로 받은 주문의 부분 반품으로 잔여 금액이 3만원 미만이 되면 최초 배송비 3,000원이 추가 차감됨을 안내한다.

[상황 5] 구매 1년 후 패킹 누수 문의

1. "패킹은 소모품으로 보증기간이 6개월입니다. 구매 후 1년이 지나 무상 교체는 어렵습니다."
2. "패킹 세트는 3,500원에 구매하실 수 있고, 공식몰 부품 카테고리에서 주문 가능합니다."
3. 정품 등록 고객이면 소모품 20% 할인 쿠폰 발급 여부를 확인해 안내한다.
4. 본체에서 새는 것인지 패킹에서 새는 것인지 불분명하면 사진 접수 후 AS로 전환한다.

[상황 6] 리콜 대상 여부 문의

1. "걱정을 끼쳐 드려 죄송합니다. 제품 바닥면의 로트 번호를 불러 주시면 대상 여부를 바로 확인해 드리겠습니다."
2. 대상이면: "리콜 대상으로 확인됩니다. 사용을 중지해 주시고, 무상 교환과 전액 환불 중 원하시는 방법을 말씀해 주세요. 배송비는 전액 저희가 부담합니다."
3. 비대상이면: "고객님 제품은 해당 로트 범위에 포함되지 않습니다. 그래도 불안하시면 표준 테스트 절차를 안내해 드리겠습니다."
4. 리콜 원인에 대한 추측성 답변은 하지 않고 공지문 내용만 안내한다.

[상황 7] 냄새·물때 제거 문의

1. "세척 방법으로 대부분 해결되는 증상입니다. 방법을 안내해 드리겠습니다."
2. 냄새: "베이킹소다 1티스푼을 미온수에 녹여 1시간 담근 후 세척해 보세요. 커피나 차 착색은 2~3회 반복하면 대부분 제거됩니다."
3. 물때: "구연산 1~2티스푼을 미온수에 녹여 30분 담근 후 세척해 주세요."
4. 염소계 표백제, 철수세미, 식기세척기는 제품 손상의 원인이 되고 유상 AS 처리될 수 있음을 함께 고지한다.
5. 안내 후에도 증상이 지속되면 재인입 시 AS 접수로 전환한다.
